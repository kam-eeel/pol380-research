# Operation Doppelgänger and EU public support for Ukraine

Operation Doppelgänger is the Russian disinformation campaign that cloned European news sites. Did documented exposure to it erode public support in EU member states for military aid to Ukraine and for sanctions on Russia?

This repository holds the data construction, analysis, and outputs behind the paper. The design is a country-wave panel: 27 member states across seven Eurobarometer waves (EB 97.5 to 103.3, June 2022 to April 2025, N = 189). Estimation uses two-way fixed effects (TWFE), with inference by restricted wild cluster bootstrap clustered by country.

## Findings in brief

- Documented exposure has no detectable effect on support for either policy (primary model: +0.34 points per exposure tier for aid, p = 0.70; +0.19 for sanctions, p = 0.71).
- At equivalence bounds fixed before testing, erosion as large as the EU-wide decline in support over the period is ruled out for both outcomes. For aid, erosion of more than about 2.3 to 2.7 points for a move from no documented exposure to the top tier is ruled out. For sanctions, the result is less robust.
- Two-sided equivalence is not established: the intervals extend to large positive effects, a tail traced to the final-wave coding of France, Italy, and Poland.

The notebook generates all reported figures in `output/manuscript_numbers.md`. That file also lists superseded figures from the earlier version of the paper.

## Repository layout

| Path | Contents |
|---|---|
| `analysis.ipynb` | The full pipeline, from raw Eurobarometer tables to every table and figure |
| `helpers.py` | Data extraction, exposure coding, and the inference routines (wild bootstrap, test-inversion intervals, equivalence tests, placebo simulation, heterogeneity-robust estimators) |
| `data/raw/` | Eurobarometer Volume A country tables, one file per wave |
| `data/interim/` | Derived data: exposure coding, source register, controls, panel, and cached simulations |

| `output/manuscript_numbers.md` | Every figure the manuscript may quote, generated by the notebook |

This repository does not distribute the forensic reports used to code exposure. The file `data/interim/source_register.csv` lists each report with its full citation and URL.

## Reproducing the analysis

The analysis requires Python 3.14. To reproduce it, follow these steps:

1. Create a virtual environment, install the requirements, and open the notebook:

   ```python
   python -m venv .venv
   .venv/bin/python -m pip install -r requirements.txt
   .venv/bin/python -m jupyter lab analysis.ipynb
   ```

2. Optional: To re-run the two placebo simulations, delete their cached results in `data/interim/placebo_rejection_rates*.csv`. Each simulation takes a few minutes.
3. Run all cells.

The notebook reads its cached inputs in `data/interim/` where they exist. Otherwise, it rebuilds them and retrieves controls from the Eurostat API. A full run with the caches in place takes about five minutes.

## Pre-commitment

The original hypotheses, models, and robustness checks R1 to R4 were fixed before estimation. Checks R5 to R8 were added after the first results. After the main estimates were known, each additional analysis was committed to `docs/decision_log.md` before it was run.
